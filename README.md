# 🔐 Secure Digital Vault using User Behavioural Analysis

An AI-powered adaptive cybersecurity platform that combines behavioral biometrics, continuous authentication, anomaly detection, deception-based security, and encrypted digital storage to protect sensitive assets from unauthorized access and suspicious activities.

---

# 🚀 Project Overview

Secure Vault is an intelligent cybersecurity system designed to provide real-time adaptive authentication and secure digital storage using machine learning and user behavioral analysis.

Unlike traditional authentication systems that rely only on passwords or OTPs, this system continuously monitors user behavior such as typing patterns, mouse movements, navigation flow, session activity, device information, and IP behavior to dynamically evaluate trust levels and detect anomalies.

The platform integrates multiple layers of security including:
- Behavioral biometrics
- Continuous authentication
- Risk-based access control
- Device fingerprinting
- IP tracking and blocking
- AI-assisted threat analysis
- Deception-based honeypot security

# 🧠 Machine Learning Workflow

The system uses the Isolation Forest anomaly detection algorithm to continuously monitor user behavior and detect suspicious activities in real time.

### Behavioral Parameters Monitored
- Typing speed
- Keystroke intervals
- Mouse movement patterns
- Navigation behavior
- Session timing
- Click frequency
- Scroll activity

### ML Workflow
1. Collect live user behavioral data
2. Normalize and process input
3. Generate anomaly scores
4. Evaluate risk level
5. Dynamically adjust authentication trust
6. Trigger alerts or protective actions

---

# 📊 Risk-Based Authentication

The platform dynamically calculates user trust and session risk.

| Risk Level | Action |
|------------|--------|
| Low Risk | Allow Access |
| Medium Risk | OTP Verification |
| High Risk | Block / Redirect to Decoy Vault |

---

# 🎭 Decoy Vault System

The Decoy Vault is a deception-based cybersecurity mechanism designed to protect sensitive information by redirecting suspicious users into a controlled fake environment.

### Features
- Fake files and folders
- Simulated vault behavior
- Attacker activity monitoring
- Threat logging
- Silent security alerts

This improves intrusion detection while protecting actual user assets.
